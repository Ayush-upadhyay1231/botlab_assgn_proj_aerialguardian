# Botlab AerialGuardian Project

This repository contains the source code for the Aerial Guardian and ByteTrack systems.

## Dataset Setup
Because the raw VisDrone dataset files are too large for GitHub, they are excluded from this repository. 
To run this project locally:
1. Download the VisDrone dataset raw files.
2. Create a folder named `data` inside the `AerialGuardian` directory.
3. Place your raw images and annotations inside `AerialGuardian/data/` exactly as required by the scripts.
